# yanndurandet.me

Personal one-pager, live at https://yanndurandet.me. Plain HTML, no build step, no JS dependencies.

- `index.html` – the whole site (CSS inline). Shows French copy (`data-fr`) when the browser language is French.
- `assets/` – deployed images and self-hosted IBM Plex Serif subsets (WebP / WOFF2).
- `source-assets/` – original images, not deployed. Thumbnails: `scripts/optimize-images.sh` (needs `cwebp`). Favicons + OG images: `npm i --no-save sharp && node scripts/optimize-icons.mjs`.
- `icon.svg`, `favicon.ico`, `apple-touch-icon.png` (site root) and `assets/og*.png` – generated by the script above.
- Hosted as a Cloudflare Worker with static assets (`wrangler.jsonc`); `.assetsignore` lists what is not deployed.

Preview locally: `python3 -m http.server 8123`, then open http://localhost:8123.
